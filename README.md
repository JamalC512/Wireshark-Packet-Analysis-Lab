# Wireshark Packet Analysis Lab

## Project Overview

The Wireshark Packet Analysis Lab was a network forensics project where I analyzed captured network traffic to investigate suspicious HTTP activity. This project gave me hands-on experience using Wireshark to examine packets and understand what was happening across a network.

## What I Did

During the lab, I used Wireshark to analyze captured network traffic and identify important information such as source and destination IP addresses, MAC addresses, protocols, and other packet details.

I also examined HTTP traffic and inspected HTTP POST data to understand the activity taking place between systems. By following packets and comparing information throughout the capture, I was able to reconstruct a timeline of activity and identify where suspicious web traffic originated.

I used different Wireshark filters to narrow down the traffic I needed to investigate and focused on relevant packets instead of analyzing the entire capture at once.

The project also helped strengthen my network troubleshooting and cybersecurity investigation skills.
